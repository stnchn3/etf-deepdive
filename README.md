This is a project I worked on that used Selenium and Beautiful Soup to find information on various ETFs and the stocks that they are invested in. Then, using Wikipedia and AI summarization tools, short summaries of each company were made. After testing multiple embedding models on different sources of information, we were able to create a semantic search engine for investment themes.

The final result is a recommendation memo that suggested which stocks to invest in for the best long-term success.
